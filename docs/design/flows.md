# User Flows and Navigation

[← 디자인 계약으로 돌아가기](../../design.md)

출시 사용자 여정, 화면 순서, 뒤로 가기, 결과와 장소 선택의 정보 구조를 정의한다.

## User Journey and Screen Order

### First-time journey

| 단계         | 경로                        | 사용자 목표             | 화면의 Primary 행동                | 영향  |
| ------------ | --------------------------- | ----------------------- | ---------------------------------- | ----- |
| 1. 시작      | `/`                         | 서비스 가치 이해        | `여행 성향 알아보기`               | `[F]` |
| 2. 성향 검사 | `/onboarding`               | 질문에 답하기           | 답변 선택 후 자동으로 다음 문항     | `[F]` |
| 3. 결과      | `/onboarding/result`        | 유형 이해               | 닉네임 입력 후 `여행 시작하기`     | `[V]` |
| 4. 장소 선택 | `/places`                   | 기간 설정·장소 담기     | `담은 장소로 코스 만들기`          | `[B]` |
| 5. 코스 확인 | `/course/[courseId]`        | 동선과 소요 시간 확인   | `이 코스로 진행`                   | `[F]` |
| 6. 코스 상세 | `/course/[courseId]/detail` | 시간대별 일정 확인·수정 | `이 코스 사용`                     | `[F]` |
| 7. 탐험      | `/explore/[courseId]`       | 길 찾기·방문 인증       | 현재 장소의 `지도 밝히기`          | `[B]` |
| 8. 기록      | `/record`                   | 완료한 여행 회고·공유   | `여행 기록 보기/공유`              | `[B]` |

### Returning journey

- 진행 중 탐험이 있으면 홈에서 해당 탐험으로 이동한다.
- 진행 중 탐험이 없으면 장소 선택 또는 사용자의 코스 허브로 이동한다. 어느 쪽인지 백엔드 상태 계약 후 확정한다. `[B]`
- 자동 이동을 수행하는 동안 빈 화면을 노출하지 않고 짧은 세션 확인 상태를 보여준다. `[F]`
- 자동 이동 실패 시 가장 안전한 유효 경로 하나를 안내한다.

### Flow rules

- 홈 스크롤 애니메이션은 장식적 진행이다. 스크롤 끝에서 예고 없이 자동 이동하지 않고 명시적 CTA를 제공한다. `[F]`
- 성향 검사는 답변 선택 상태를 짧게 보여준 뒤 자동으로 다음 문항으로 이동한다. `이전 질문`으로 답변을 수정할 수 있다. `[F]`
- 사용자가 상세 화면을 보고 돌아오면 카드 순서, 선택 장소, 스크롤 위치를 보존한다. `[F]`
- 로그인·등록·방문 인증 성공은 성공 상태를 보여준 뒤 다음 화면으로 이동한다.

## Navigation and Back Behavior

### Global rules

1. 오버레이가 열려 있으면 Back은 오버레이를 닫는다.
2. 중첩 화면이면 Back은 명시된 부모 화면으로 이동한다.
3. 선형 작업 중이면 Back은 이전 단계로 이동하고 입력값을 보존한다.
4. Home은 현재 작업을 끝내고 홈으로 이동한다. 저장되지 않은 선택을 잃는 경우 한 번 확인한다.
5. 브라우저 history가 비어 있거나 외부 딥링크로 들어와도 중요한 Back에는 fallback 경로를 정의한다. `[F]`

| 화면               | 좌측 행동   | 시스템·브라우저 Back                          |
| ------------------ | ----------- | --------------------------------------------- |
| 홈                 | 없음        | 브라우저 기본 동작                            |
| 성향 검사 첫 문항  | `나가기`    | 홈. 답이 있으면 손실 확인                     |
| 성향 검사 2번 이후 | `이전 질문` | 이전 질문                                     |
| 결과               | Home        | 성향 마지막 문항 또는 홈 정책을 제품에서 확정 |
| 장소 선택          | Back        | 결과. 선택 상태 보존                          |
| 장소 상세 시트     | Close       | 시트 닫기                                     |
| 코스 지도          | Back        | 장소 선택 또는 코스 허브                      |
| 코스 상세          | Back        | 같은 코스 지도                                |
| 탐험               | Home/Menu   | 탐험 이탈 확인 후 홈                          |
| 기록               | Back/Home   | 진입한 상위 화면                              |

현재 서비스는 선형 여정이므로 하단 내비게이션을 새로 추가하지 않는다. Home과 Menu만으로 반복 방문 목적지가 실제로 발견되지 않는다는 사용자 테스트 결과가 있을 때 검토한다.

## Result Screen Priority

### First-time user

1. 유형명과 핵심 설명
2. 키워드 2~4개
3. 닉네임 등록과 `여행 시작하기`
4. 추천 장소 2개 미리보기
5. `추천 장소 모두 보기`
6. 결과 이미지 공유
7. 다시 검사

닉네임 등록은 추천 장소 전체 목록 아래에 두지 않는다. 공유는 핵심 서비스 진입보다 시각적으로 강해서는 안 된다. `[V]`

### Returning user

1. 유형명과 핵심 설명
2. `추천 장소 보러 가기`
3. 추천 장소 미리보기
4. 결과 공유
5. 다시 검사

### Share sheet

- `화면 그대로`는 실제 화면 캡처가 아니므로 `결과 카드`로 명명한다. `[V]`
- 버전 이름은 `결과 카드`, `우표 엽서`로 사용한다.
- 미리보기, 저장, 공유 순으로 배치한다.
- Web Share API를 사용할 수 없으면 공유 버튼을 숨기지 않고 저장 fallback을 설명한다. `[F]`

## Place Selection and Completion

### Travel period

- 장소 추천 전에 `당일치기`, `1박 2일`, `2박 3일`, `그 이상`과 여행 날짜를 정한다.
- 기간별 코스 생성 최소 선택 수는 각각 `3`, `5`, `7`, `20`곳이다.
- 기간을 바꿔도 이미 담은 장소는 보존하고 변경된 최소 개수를 즉시 안내한다.

### Language

- `좋아요` → `담기`
- `싫어요` → `넘기기`
- `좋고 싫음을 알려주세요` → `가고 싶은 장소를 골라주세요`
- 하트는 저장·담기의 의미가 충분히 명확할 때만 유지하고 접근성 이름은 `장소 담기`로 제공한다.

### Card anatomy

1. 실제 장소 사진 또는 브랜드 fallback
2. 장소 카테고리
3. 장소명
4. 성향과 연결된 추천 이유 한 줄
5. 탭 시 상세 정보

### Interaction

- 오른쪽 스와이프와 `담기` 버튼은 같은 동작이다.
- 왼쪽 스와이프와 `넘기기` 버튼은 같은 동작이다.
- `되돌리기`는 직전 한 건만 복원한다.
- 도움말은 사용자가 카드를 한 번 본 뒤에도 항상 다시 열 수 있다.
- 진행 표시는 `확인 3/12`처럼 의미를 포함한다.

### Completion

| 상태                    | 제목                               | Primary                     | Secondary              |
| ----------------------- | ---------------------------------- | --------------------------- | ---------------------- |
| 기간별 최소 개수 충족   | `코스를 만들 준비가 됐어요`        | `N곳으로 코스 만들기` `[B]` | `선택 다시 보기` `[F]` |
| 최소 개수 미충족        | `N곳만 더 담아주세요`              | `장소 더 보기` `[F]`        | `선택 다시 보기` `[F]` |
| 0개 담음                | `아직 담은 장소가 없어요`          | `장소 다시 보기` `[F]`      | 없음                   |
| 추천 데이터 없음        | `추천 장소를 준비하지 못했어요`    | `다시 시도`                 | Home                   |

완료 상태를 축하 문구만 있는 막다른 화면으로 만들지 않는다.
