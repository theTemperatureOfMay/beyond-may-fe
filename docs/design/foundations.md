# Foundations

[← 디자인 계약으로 돌아가기](../../design.md)

색상, 타이포그래피, 간격, 깊이, 형태에 관한 시각 기준이다. 새 화면을 만들 때 임의 값을 추가하기 전에 이 문서를 확인한다.

## Colors

색은 **종이 같은 바탕, 먹색 정보, 일출색 브랜드, 장소 유형색**의 네 층으로 운영한다.

| 역할                | 토큰                                             | 사용                                      |
| ------------------- | ------------------------------------------------ | ----------------------------------------- |
| 앱 캔버스           | `{colors.canvas}`                                | 대부분의 페이지 배경                      |
| 떠 있는 표면        | `{colors.surface}`                               | 지도 컨트롤, 모달, 시트                   |
| 기본 텍스트·주 행동 | `{colors.ink}`                                   | 제목, 본문, Primary 버튼                  |
| 보조 텍스트         | `{colors.ink-muted}`                             | 설명, 메타 정보. 캔버스 대비 5.91:1       |
| 브랜드 장면         | `{colors.brand-orange}`, `{colors.brand-violet}` | 홈, 완료, 공유 결과에 한정                |
| 포커스              | `{colors.focus}`                                 | 모든 키보드 포커스 링                     |
| 오류                | `{colors.error}`, `{colors.error-surface}`       | 사용자가 수정하거나 재시도할 수 있는 오류 |
| 지도                | `{colors.route}`, `{colors.location}`            | 동선과 현재 위치                          |

### Personality colors

- 사색러: `{colors.type-thinker}`
- 미식러: `{colors.type-foodie}`
- 예술러: `{colors.type-artist}`
- 기억러: `{colors.type-remember}`

유형색은 분류와 결과 표현에만 사용하고 성공·오류·선택 상태를 대신하지 않는다. 색만으로 유형이나 방문 상태를 구분하지 않고 이름, 번호, 체크 등의 표식을 함께 제공한다.

### Contrast rules

- 일반 텍스트는 배경과 최소 `4.5:1`, 큰 텍스트와 UI 경계는 최소 `3:1`을 만족한다.
- 작은 본문에 기존 `neutral-05 (#BEC2C0)`를 사용하지 않는다.
- 브랜드 그라디언트 위에 16px 미만 텍스트를 직접 올리지 않는다. 단색 영역, 로컬 스크림 또는 불투명 정보 표면을 사용한다.
- `{colors.brand-orange}` 위에는 기본적으로 `{colors.ink}`를 사용한다.
- 이미지 위 텍스트는 이미지 내용과 무관하게 대비가 유지되는 하단 스크림을 가진다.

## Typography

Pretendard JP의 실제 포함 굵기인 `400`, `500`, `600`, `700`만 사용한다. `font-light`와 `font-extrabold`처럼 제공되지 않은 굵기를 브라우저가 합성하게 하지 않는다.

| 역할       | 토큰                       | 용도                              |
| ---------- | -------------------------- | --------------------------------- |
| Display    | `{typography.display}`     | 홈 서비스명 전용. 한 화면에 한 번 |
| Headline L | `{typography.headline-lg}` | 성향 결과명 등 대표 결과          |
| Headline M | `{typography.headline-md}` | 질문 번호와 핵심 문장             |
| Title L    | `{typography.title-lg}`    | 화면·섹션 제목                    |
| Title M    | `{typography.title-md}`    | 카드·모달 제목                    |
| Body L     | `{typography.body-lg}`     | 긴 설명과 중요 안내               |
| Body M     | `{typography.body-md}`     | 기본 본문과 버튼                  |
| Body S     | `{typography.body-sm}`     | 보조 설명                         |
| Label      | `{typography.label}`       | 배지, 메타 정보, 짧은 상태        |

### Typography rules

- 새 `11.6px`, `13.4px`, `19.2px` 같은 일회성 크기를 만들지 않는다.
- 한 화면에서 사용하는 굵기는 기본적으로 두 가지, 최대 세 가지로 제한한다.
- 한국어 본문은 왼쪽 정렬을 기본으로 한다. 짧은 완료·로딩 메시지만 중앙 정렬할 수 있다.
- 본문 한 줄은 모바일에서 약 22~32자를 목표로 하며 긴 설명은 문단을 나눈다.
- 영문 대문자와 넓은 자간은 `GWANGJU · BEYOND MAY` 같은 브랜드 서명에만 사용한다.

## Layout

서비스는 모바일 우선 PWA이며, 모든 실제 페이지는 동일한 앱 프레임을 사용한다.

- 지원 너비: `320px` 이상
- 기준 검수 너비: `360px`, `390px`, `430px`
- 앱 프레임 최대 너비: `430px`
- 기본 콘텐츠 gutter: `{spacing.gutter}`
- 헤더·소형 시트의 압축 gutter: `{spacing.lg}`
- 세로 간격은 YAML의 4px 기반 spacing scale만 사용한다.
- 데스크톱에서는 앱을 늘리지 않고 중앙의 430px 프레임으로 표시한다.
- 지도, 코스, 탐험 화면도 동일한 프레임 규칙을 적용한다.
- 고정 헤더·하단 CTA·바텀시트에는 `safe-area-inset-top/bottom`을 더한다.
- 화면 높이는 `dvh`를 기준으로 하고 주소창 변화에도 주 행동이 가려지지 않아야 한다.

### Content layout

- 기본 섹션 간격은 32px, 강한 장면 전환은 48~64px를 사용한다.
- 제목과 설명은 8px, 설명과 첫 입력·행동은 16~24px 떨어뜨린다.
- 카드 내부 여백은 16px 또는 24px 중 하나를 사용한다.
- 사진 캐러셀을 제외하고 가로 스크롤을 만들지 않는다.
- 장소 카드 높이는 고정 536px 대신 가용 화면 높이에 맞춰 줄어들어야 한다. 카드, 헤더, 하단 조작부가 320×568 화면에도 함께 보여야 한다. `[V]`

## Elevation & Depth

깊이는 그림자보다 **표면색, 테두리, 배경 흐림**으로 만든다.

| 단계     | 처리                          | 용도                         |
| -------- | ----------------------------- | ---------------------------- |
| Base     | 그림자 없음                   | 페이지, 목록, 일반 카드      |
| Floating | `0 2px 8px rgba(0,0,0,.14)`   | 지도 버튼, 카드 위 원형 액션 |
| Overlay  | `0 12px 40px rgba(0,0,0,.22)` | 중앙 모달                    |

- Primary 버튼에 장식용 그림자를 사용하지 않는다.
- 같은 화면에서 서로 다른 그림자 공식을 섞지 않는다.
- 오버레이는 기본 `rgba(0,0,0,.5)`를 사용한다.
- 장소 상세처럼 배경 맥락을 남겨야 하는 시트만 약한 오버레이와 blur를 사용할 수 있다.

## Shapes

- `{rounded.sm}`: 작은 배지와 보조 표면
- `{rounded.md}`: 입력, 작은 카드, 오류 블록
- `{rounded.lg}`: 중앙 모달
- `{rounded.xl}`: 바텀시트의 위쪽 모서리
- `{rounded.hero-card}`: 장소 스와이프 대표 카드 전용
- `{rounded.full}`: 버튼, 칩, 진행 표시, 원형 컨트롤

우표 톱니는 브랜드 시그니처다. 결과와 공유 기록에서만 사용하고 일반 카드·입력·지도 패널에 확장하지 않는다. 드래그할 수 없는 시트에는 드래그 핸들을 표시하지 않는다.

## Do's and Don'ts

- **Do** 오프화이트, 차콜, 일출색, 우표, 흑백 지도를 핵심 정체성으로 유지한다.
- **Do** 중요한 화면 전환과 완료 순간에만 브랜드 색을 사용한다.
- **Do** 실제 장소 사진과 실제 길이의 한국어 콘텐츠로 검수한다.
- **Do** 모든 빈 화면에 하나의 유효한 다음 행동을 제공한다.
- **Do** 기존 `Button`, `CircleIconButton`, `Modal`, `PlaceDetailSheet`를 우선 개선하고 재사용한다.
- **Don't** 역사·추모 장소에 `싫어요`라는 표현을 사용한다.
- **Don't** 모든 CTA를 주황색으로 만들거나 모든 카드에 우표 장식을 추가한다.
- **Don't** 새 색, radius, 글자 크기, 그림자 값을 화면마다 즉석에서 추가한다.
- **Don't** 클릭할 수 없는 아이콘, 동작하지 않는 버튼, 드래그되지 않는 핸들을 노출한다.
- **Don't** 단순한 스타일 통일을 위해 새 UI 라이브러리를 추가한다.
- **Don't** 권한 거부와 네트워크 오류를 동일한 일반 오류로 처리한다.
