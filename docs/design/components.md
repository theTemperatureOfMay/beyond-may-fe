# Components and Interaction States

[← 디자인 계약으로 돌아가기](../../design.md)

공용 컴포넌트의 형태와 동작 상태를 정의한다. 화면별 복제보다 기존 컴포넌트 개선을 우선한다.

## Button

- 한 화면에는 Primary 버튼을 하나만 둔다.
- Primary는 차콜 배경, Secondary는 차콜 테두리, Tertiary는 텍스트 버튼이다.
- 기본 높이는 48px, 아이콘 전용 버튼의 터치 영역은 최소 44×44px다.
- 버튼 텍스트는 행동과 결과를 함께 표현한다. `다음`, `확인`보다 `담은 장소로 코스 만들기`를 우선한다.
- 스와이프, 드래그, 제스처 기능에는 동일 동작을 수행하는 탭 버튼을 함께 제공한다.

| 상태     | 표현                                | 동작                     |
| -------- | ----------------------------------- | ------------------------ |
| Default  | 완전한 대비                         | 활성                     |
| Pressed  | 92% 명도 또는 미세한 축소           | 포인터 해제 시 실행      |
| Focus    | 2px 이상 `{colors.focus}` 링        | 키보드 사용 시 항상 표시 |
| Loading  | 라벨 유지 + 작은 진행 표시          | 중복 제출 금지           |
| Disabled | 낮은 대비 + 이유를 인접 문구로 설명 | 클릭 불가                |

## Input

- 라벨은 placeholder로 대체하지 않는다.
- 높이 48px, 좌우 16px, `{rounded.md}`를 사용한다.
- 포커스는 2px `{colors.focus}`, 오류는 `{colors.error}` 테두리와 구체적인 도움말을 함께 표시한다.
- 오류 발생 시 사용자가 입력한 값을 지우지 않는다.
- 닉네임 글자 수처럼 제약이 있는 경우 입력 전에 helper text로 알리고 현재 값을 함께 표시한다.

## Modal and Bottom Sheet

- **Modal:** 지금 작업을 계속하려면 즉시 선택이 필요한 경우에만 사용한다.
- **Bottom sheet:** 현재 맥락을 유지한 채 상세, 목록, 공유 행동을 보여줄 때 사용한다.
- 브라우저·시스템 뒤로 가기는 열린 오버레이를 먼저 닫는다. `[F]`
- 모달은 열린 뒤 제목 또는 첫 컨트롤로 포커스를 이동하고, 닫은 뒤 트리거로 복원한다. `[F]`
- `Escape`, 명시적 닫기 버튼, 허용된 경우 backdrop 탭으로 닫을 수 있다.
- 파괴적이거나 데이터 손실이 있는 작업은 backdrop 탭으로 닫지 않는다.
- 시트 핸들은 실제 드래그 닫기가 구현된 경우에만 표시한다.

## Header

- 홈에서는 Home 아이콘을 표시하지 않는다.
- Back은 현재 작업의 이전 단계, Home은 전체 여정의 시작, Menu는 부가 목적지에 사용한다.
- 가운데 영역은 진행 상태 또는 팀 상태 중 하나만 표시한다.
- 지도 위 헤더는 순백색 원형 표면을 사용하되 아이콘·터치 크기 규칙은 일반 헤더와 같다.
- 숨겨진 헤더는 `opacity: 0`뿐 아니라 포인터와 키보드 포커스도 비활성화한다. `[F]`

## Cards

- 장소 선택 카드는 이미지, 카테고리, 장소명, 추천 이유 한 줄을 포함한다.
- 결과 추천 목록은 이미지, 장소명, 한 줄 설명까지만 기본 노출한다.
- 이미지가 없을 때 단순 회색 박스 대신 브랜드 아치 또는 지도 패턴과 장소명을 사용한다. `[V]`
- 카드 전체가 클릭 가능하면 내부에 중복 클릭 목표를 만들지 않는다.

## Progress and Feedback

- 진행률은 색과 너비뿐 아니라 `현재/전체` 텍스트 또는 접근성 값으로 제공한다.
- Toast는 사용자의 행동 결과만 알리고 다음 행동을 대신하지 않는다.
- 방문 완료는 체크, 문구, 핀 변화로 동시에 전달한다.
- 로딩 진행은 스크린 리더에 `role="status"` 또는 `aria-live`로 알린다.

## Map

- 지도 타일은 탐험 모드에서 흑백으로 시작하고 방문 장소 주변에 유형색 glow를 남긴다.
- “도시 전체가 컬러로 바뀐다”고 약속하지 않는다. 실제 표현은 “방문한 장소에 빛을 남긴다”로 설명한다.
- 핀은 번호, 체크, 깃발을 사용해 색 없이도 상태를 구분한다.
- 지도 로드 실패 시 같은 장소 순서의 목록으로 대체한다.
- 지도 제스처만으로 수행해야 하는 핵심 기능을 만들지 않는다.

## Interaction State Matrix

모든 인터랙티브 컴포넌트는 최소 다음 상태를 설계하고 구현한다.

| 컴포넌트       | 필수 상태                                            |
| -------------- | ---------------------------------------------------- |
| Button         | default, pressed, focus, loading, disabled           |
| Input          | empty, filled, focus, error, disabled                |
| Quiz option    | unselected, selected, focus                          |
| Place card     | top, background, dragging, exiting, missing-image    |
| Map pin        | default, current, visited, clustered, focus/selected |
| Modal/Sheet    | entering, open, exiting                              |
| Network action | idle, pending, success, recoverable error            |

- 선택 상태를 다른 요소의 흐림만으로 표현하지 않는다.
- disabled는 오류를 숨기는 수단이 아니다. 사용자가 해결할 수 있으면 이유를 보여준다.
- pending 중에는 버튼 문구가 완전히 다른 의미로 바뀌지 않도록 원래 목적을 유지한다.
